## 1. 🌐 Overview
The **NEU Library Portal** is the official gateway for New Era University students and staff to access academic resources and manage library operations.  It provides secure, role-based access via institutional Google accounts, with customizable interface options including Dark Mode,  Light Mode, and  System Default themes.

---

## 2. 🔑 Access Options
| Portal         | Description                                                                 | Access Type                        |
|----------------|-----------------------------------------------------------------------------|------------------------------------|
| 🎓 **Student Portal** | For enrolled students to access library services and check in.              | Institutional Account (**@neu.edu.ph** only) |
| 🛠️ **Admin Portal**   | For authorized staff to manage attendance, monitor usage, and access analytics. | Authorized Staff Only              |

---

## 3. 🎓 Student Workflow

### 🔐 Login Interface
- **Login Method:** Institutional Google account only.  
- **Allowed Accounts:** Must end with **@neu.edu.ph**.  
- **Restriction:** Non-NEU accounts are blocked from proceeding.  
- **Authentication Button:** *Continue with Google*.  

### 📊 Dashboard Interface
- **Check-in Form:** Purpose of Visit, College/Department, Program/Course.  
- **Library Info Panel:** Operating hours and available services.  
- **🎨 Theme System Button:** Students can switch between **🌙 Dark Mode**, **☀️ Light Mode**, or **⚙️ System Default**.  

### ✅ Confirmation Screen
- Displays student details and confirms visit logging.  
- ⏱️ Countdown timer returns to login screen.  
- *✔️ Done* button allows manual exit.  

---

## 4. 🛠️ Admin Workflow

### 🔐 Login Interface
- **Login Method:** Institutional Google account.  
- **Restriction:** Only authorized staff accounts permitted.  
- **Purpose:** Access library management tools.  

### 📊 Admin Dashboard – “LIVE MONITORING PULSE”
- Strategic analysis of attendance.  
- Filters: **📅 Today, 📆 Week, 🗓️ Month, 🎯 Custom Range**.  
- **Custom Range Selector:** Calendar-based date selection.  
- 📄 *Download Full Report* generates the **NEU Library Comprehensive Report**, which includes:  
  1. 📊 Core Strategic Metrics  
  2. 🏫 Institutional Attendance Breakdown  
  3. 🎯 Visit Purpose Distribution  
  4. ⏱️ Temporal Traffic Patterns  
  5. 📑 Historical Entry Registry  
- **🎨 Theme System Button:** Admins can toggle **🌙 Dark Mode**, **☀️ Light Mode**, or **⚙️ System Default**.  

### 🔒 Access Control
- 👥 Manage student permissions and monitor institutional access.  
- 🔍 Search directory, block/unblock accounts.  
- 🟢 Status indicators: Database ONLINE, Security STABLE.  

### 🗂️ Audit Logs
- 📜 Historical record of all library entries and visitor activities.  
- 🔍 Search and filter by name, college, or program.  
- 📄 *Download Report* for compliance and record-keeping.  

---

## 5. 🔐 Security Notes
- Authentication handled via Google OAuth.  
- Only **@neu.edu.ph** accounts are permitted for students.  
- Admin access restricted to authorized staff.  
- 🚫 Unauthorized accounts are blocked.  
- 📝 All check-ins, admin actions, and audit logs are recorded.
